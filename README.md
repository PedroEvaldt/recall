# recall

![status-badge](http://192.168.76.202:8000/api/badges/1/status.svg)

> Self-hosted document recall service for the terminal.

`recall` combines a Go HTTP API, a Cobra-based CLI, local file storage, and
PostgreSQL metadata so personal notes can be uploaded, searched, and opened
from any machine that can reach the server.

## Background

The project is in an early milestone. The core upload, list, and get flows
work end-to-end, along with bearer-token authentication, tags, the terminal
UI, Docker, Kubernetes manifests, and CI.

Features:

- HTTP API for document upload, metadata lookup, search, and content download.
- CLI client with `init`, `upload`, `list`, and `get` commands.
- Bearer-token authentication for every endpoint except `/health`.
- PostgreSQL metadata with title/tag search and soft-delete filtering.
- Local filesystem blob storage partitioned by UUID prefix.
- Type-safe database access generated by [sqlc](https://docs.sqlc.dev/).
- Versioned migrations managed by [goose](https://pressly.github.io/goose/).
- Terminal UI flows built with Bubble Tea, Bubbles, Lip Gloss, and Glamour.
- Docker, docker compose, Kubernetes manifests, and Woodpecker CI pipelines.

Architecture:

```text
┌──────────────┐          ┌─────────────────┐          ┌────────────┐
│  recall CLI  │ ──HTTP──▶│  recall server  │ ──SQL──▶ │ PostgreSQL │
│ (cmd/recall) │          │  (cmd/server)   │          └────────────┘
└──────────────┘          │                 │          ┌────────────┐
                          └─────────────────┘ ──FS──▶  │  storage/  │
                                                       └────────────┘
```

A file-by-file walkthrough lives in
[docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md).

## Install

Prerequisites:

- Go 1.26.2 or newer.
- Docker, or a local PostgreSQL 16 instance.
- [`goose`](https://pressly.github.io/goose/) for migrations.
- [`sqlc`](https://docs.sqlc.dev/) when changing SQL queries or schemas.
- `make`.

CLI only, from source:

```bash
go install github.com/PedroEvaldt/recall/cmd/recall@latest
```

Full project (server + CLI), from source:

```bash
git clone https://github.com/PedroEvaldt/recall.git
cd recall
cp .env.example .env
make db-up        # start PostgreSQL
make goose-up     # apply database migrations
make build        # build binaries into bin/
```

## Usage

After installing, start the server and configure the CLI:

```bash
# Start the server (uses .env in the current directory).
make run-server

# In another terminal, create the CLI config file.
recall init
```

Then upload, list, and retrieve documents:

```bash
recall upload notes/go-structs.md --title "Go structs" --tags go,types
recall list "go struct"
recall get  "go struct"
```

### CLI Reference

```text
recall [command] [flags]
```

Global flags:

| Flag | Description |
| --- | --- |
| `-s, --server` | Server URL. Overrides `RECALL_SERVER`. |
| `--auth-token` | Bearer token. Overrides `RECALL_AUTH_TOKEN`. |

#### `recall init`

Create `$HOME/.config/recall/config.yaml`. If no token is provided in the TUI,
the command generates a random token that must also be configured on the
server as `AUTH_TOKEN`.

#### `recall upload <file> [-t title] [--tags tag1,tag2]`

Upload a local file. The server stores the file under `STORAGE_PATH` and
persists metadata in PostgreSQL.

| Flag | Description |
| --- | --- |
| `-t, --title` | Document title. Defaults to the filename without extension. |
| `--tags` | Comma-separated tags sent as searchable metadata. |

#### `recall list <query...> [-l limit]`

Search documents by title or tag, or list all non-deleted documents with
`--all`.

| Flag | Description |
| --- | --- |
| `-l, --limit` | Maximum number of results. `0` means no explicit limit. |
| `-a, --all` | List all documents instead of searching by query. |

#### `recall get <query...>`

Search for documents, select one in the terminal UI, then print or render its
content. Markdown files are rendered with Glamour; other files are streamed to
stdout.

## API

All endpoints except `/health` require:

```text
Authorization: Bearer <AUTH_TOKEN>
```

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/health` | Liveness/readiness endpoint. Does not require authentication. |
| `POST` | `/documents` | Upload a document using multipart fields `title`, `tags`, and `file`. |
| `GET` | `/documents?q=<term>&limit=<n>` | List documents matching title or tags. Omit `q` to list all. |
| `GET` | `/documents/{id}` | Return document metadata as JSON. |
| `GET` | `/documents/{id}/content` | Stream the stored document content. |

Successful document responses use the shape defined in
[`internal/api/types.go`](internal/api/types.go):

```json
{
  "id": "311ec9da-87c2-45c1-a4f2-d7b0cf60bf35",
  "title": "Go structs",
  "mime_type": "text/markdown",
  "filename": "go-structs.md",
  "tags": ["go", "types"],
  "created_at": "2026-04-29T01:17:23Z"
}
```

Errors are returned as JSON:

```json
{ "error": "message" }
```

## Configuration

The server loads `.env` from the current directory, then reads environment
variables. The CLI reads, in order: flags, `RECALL_*` environment variables,
`.env`, and `$HOME/.config/recall/config.yaml`.

| Variable | Used by | Default | Description |
| --- | --- | --- | --- |
| `DB_URL` | server | required | PostgreSQL connection string. |
| `AUTH_TOKEN` | server | required | Bearer token accepted by the API. |
| `SERVER_HOST` | server | `localhost` | Host/IP the server binds to. |
| `SERVER_PORT` | server | `8080` | Port the server listens on. |
| `STORAGE_PATH` | server | `./storage` | Directory where uploaded file blobs are stored. |
| `RECALL_SERVER` | CLI | required | Base URL of the recall server. |
| `RECALL_AUTH_TOKEN` | CLI | required | Bearer token sent by CLI requests. |

## Development

Makefile targets:

| Target | Action |
| --- | --- |
| `make db-up` / `make db-down` | Start/stop the PostgreSQL container. |
| `make db-shell` | Open a `psql` shell in the PostgreSQL container. |
| `make goose-up` / `make goose-down` / `make goose-status` | Apply, roll back, or inspect migrations. |
| `make run-server` | Run the server with `go run`. |
| `make build` | Build server and CLI binaries into `bin/`. |
| `make install` | Install the CLI into `$GOBIN` or `$GOPATH/bin`. |

Regenerate database code after editing
`internal/storage/queries/*.sql` or `internal/storage/schemas/*.sql`:

```bash
sqlc generate
```

Generated files in `internal/storage/database` should not be edited manually.

Checks:

```bash
go fmt ./...
go test ./...
go vet ./...
```

## Deployment

- `Dockerfile` builds a static `recall-server` binary on Alpine.
- `docker-compose.yml` runs a local PostgreSQL 16 database for development.
- `k8s/postgres.yaml` defines the PostgreSQL secret, PVC, deployment, and
  service.
- `k8s/recall.yaml` defines the server deployment and service. The API secret
  is intentionally not committed and must be created in the target cluster.
- `.woodpecker/*.yaml` runs lint, test, security scan, build, and deploy
  pipelines. Pushes to `main` build and roll out a new image.
